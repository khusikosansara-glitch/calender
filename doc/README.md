# 다이어트 캘린더 프로젝트

## 프로젝트 개요
웹 기반 다이어트 관리용 캘린더 애플리케이션

## 주요 기능
- 캘린더 형태의 다이어트 기록 관리
- 다크모드 / 라이트모드 지원
- 로컬 스토리지를 활용한 데이터 저장
- 로그인 기능 (추후 구현 예정)

## 기술 스택
- HTML5
- CSS3 (CSS Variables 활용)
- Vanilla JavaScript (ES6 Modules)

## 프로젝트 구조
```
calender/
├── index.html          # 메인 HTML 파일
├── css/                # 스타일시트 디렉터리
│   ├── reset.css       # 브라우저 기본 스타일 초기화
│   ├── variables.css   # CSS 변수 (색상, 간격 등)
│   ├── theme.css       # 테마 관련 스타일
│   ├── calendar.css    # 캘린더 컴포넌트 스타일
│   └── main.css        # 메인 레이아웃 스타일
├── js/                 # JavaScript 모듈 디렉터리
│   ├── main.js         # 앱 진입점
│   ├── theme.js        # 테마 관리 모듈
│   └── calendar.js     # 캘린더 렌더링 모듈
├── doc/                # 문서 디렉터리
│   └── README.md       # 이 파일
└── assets/             # 이미지, 아이콘 등 리소스

```

## 디자인 가이드
- **배경색**: 기본 흰색 (#ffffff)
- **심플한 UI**: 불필요한 장식 요소 최소화
- **접근성**: 명확한 대비와 읽기 쉬운 폰트 사용
