# 사진 추가 기능 구현 완료 📷

## 📋 구현 요약

### ✅ 구현된 기능
1. **이미지 업로드** - 파일 선택으로 사진 추가
2. **자동 압축** - 800x800px, 품질 70%로 자동 압축
3. **미리보기** - 업로드한 사진 즉시 확인
4. **개별 삭제** - 각 사진마다 삭제 버튼

- **날짜당 최대 2장**
- **압축 후 약 300KB/장**
- **전체 약 50-100일 기록 가능**
- **브라우저 캐시 삭제 시 사진도 삭제됨**

## 🎯 1. 기능 상세

### 이미지 압축

**자동 처리:**
```
원본 이미지 (예: 5MB, 4000x3000)
    ↓
리사이징 (800x600)
    ↓
압축 (품질 70%)
    ↓
Base64 변환
    ↓
저장 (~300KB)
```

**압축 설정:**
```javascript
MAX_WIDTH = 800px
MAX_HEIGHT = 800px  
QUALITY = 0.7 (70%)
MAX_IMAGES_PER_DAY = 2장
```

### 용량 관리 시스템

**3단계 경고:**

| 사용률 | 상태 | 표시 |
|--------|------|------|
| **0-60%** | 안전 ✅ | 초록색 정보 |
| **60-80%** | 주의 ⚠️ | 노란색 경고 |
| **80%+** | 위험 🚨 | 빨간색 긴급 |

**경고 메시지:**
```
✅ 안전: 저장 공간: 2.5MB / 5MB (50% 사용 중)
⚠️ 주의: 저장 공간: 3.5MB / 5MB (70% 사용 중)
🚨 위험: 저장 공간이 85% 사용 중입니다. 일부 데이터를 삭제해주세요.
```

## 🚀 5. 사용 방법

### 사진 추가
1. 날짜 클릭 → 식사 기록 모달 열기
2. 맨 아래 "📷 사진" 섹션으로 스크롤
3. "📷 사진 추가" 버튼 클릭
4. 사진 파일 선택 (최대 2장)
5. 자동 압축 및 미리보기 표시
6. "저장" 버튼 클릭

### 사진 삭제
1. 미리보기에서 **❌ 버튼** 클릭
2. 즉시 삭제됨
3. "저장" 클릭하면 반영

### 용량 확인
- 사진 추가하면 자동으로 표시됨
- 60% 이상 시 경고 메시지
- 80% 이상 시 빨간색 긴급 경고

## ⚠️ 7. 제한 사항 상세

### LocalStorage 한계

**전체 용량:** 5-10MB (브라우저마다 다름)

**예상 사용량:**
```
이미지 1장: ~300KB
날짜 1일: ~600KB (이미지 2장)
식사 데이터: ~5KB/일

100일 기록 시:
- 이미지: 60MB (불가능!)
- 압축 후: ~6MB (가능하지만 빡빡)
```

**실제 권장:**
```
- 50일 정도 기록 (약 3MB)
- 이후 오래된 데이터 삭제 필요
- 또는 중요한 날짜만 사진 추가
```

### 영구 저장 불가

**사라지는 경우:**
- 브라우저 캐시 삭제
- 시크릿 모드 종료
- 브라우저 재설치
- 다른 기기 사용

**백업 불가:**
- 자동 백업 없음
- 클라우드 동기화 없음
- 내보내기 기능 없음

- 서버/DB 필요 (Firebase, AWS S3)

✅ 아이디어:
- 중요 사진만 클라우드

⚠️ 고려사항:
- 사용자 선택 UI 필요

## 🎯 11. 실습 과제

### 초급: 압축 품질 조정
`js/imageHandler.js`에서:
```javascript
this.QUALITY = 0.7;  // 70%
↓ 변경
this.QUALITY = 0.5;  // 50% (더 작은 파일)
this.QUALITY = 0.9;  // 90% (더 좋은 품질)
```

### 중급: 최대 이미지 개수 변경
```javascript
this.MAX_IMAGES_PER_DAY = 2;
↓ 변경
this.MAX_IMAGES_PER_DAY = 3;  // 3장으로 증가
```
※ HTML도 수정 필요: "최대 2장" → "최대 3장"

### 고급: 이미지 필터 추가
Canvas에서 흑백 필터:
```javascript
// compressImage 메서드에서
const imageData = ctx.getImageData(0, 0, width, height);
const data = imageData.data;

for (let i = 0; i < data.length; i += 4) {
    const avg = (data[i] + data[i+1] + data[i+2]) / 3;
    data[i] = avg;     // Red
    data[i+1] = avg;   // Green
    data[i+2] = avg;   // Blue
}

ctx.putImageData(imageData, 0, 0);
```

## 💬 12. 자주 묻는 질문 (FAQ)

**Q1: 사진이 자동으로 삭제되나요?**
A: 브라우저 캐시를 삭제하면 사라집니다. 중요한 사진은 별도로 백업하세요.

**Q2: 다른 기기에서도 볼 수 있나요?**
A: 아니요. LocalStorage는 기기별로 분리되어 있습니다.

**Q3: 왜 2장만 가능한가요?**
A: LocalStorage의 용량 제한(5-10MB) 때문입니다. 더 많은 사진을 저장하려면 클라우드 스토리지가 필요합니다.

**Q4: 원본 사진은 어떻게 되나요?**
A: 원본은 저장되지 않습니다. 압축된 버전만 저장됩니다.

**Q5: 용량이 가득 차면 어떻게 하나요?**
A: 오래된 날짜의 사진을 삭제하거나, 식사 기록을 정리해야 합니다.
